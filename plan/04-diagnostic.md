# 基础诊断、三个小实验与调整方法

预计题目40分钟、小实验分两次各45—60分钟。不开资料先答，随后查教程订正。诊断是学习排期工具，不是公司考核。所有实验当前为练习，未有公司运行结果。

## 12题与参考答案

| 题目 | 参考答案要点 | 对应章节 |
|---|---|---|
| 1. `uint16_t`范围？30000+30000存入`int16_t`是否等于饱和？ | 0—65535；不能把窄化当饱和，先用足够宽类型相加再夹到[-32768,32767] | T01/T04 |
| 2. `float* p`做`p+3`增加几个字节？可否解引用one-past？ | 增加3*sizeof(float)；只能形成数组末尾后一位，不能解引用，运算还须在同一数组范围 | T01 |
| 3. 返回局部数组地址、vector扩容后继续用旧data有什么问题？ | 悬垂指针；对象生命周期结束或重分配后地址失效 | T01 |
| 4. const指针能保证另一个线程不改数据吗？ | 不能；const只限制相应访问路径，需要同步及所有权规则 | T01 |
| 5. 两线程对普通int同时`++`，结果为何不可靠？ | 读改写竞争且存在C++数据竞争，属于未定义行为；用同步或符合需求的atomic | T01 |
| 6. 正常CP、μ=1时SCS和slot长度？PRB多少子载波？ | 30kHz、0.5ms；12。不要据此假设每个symbol时长完全相同 | T02 |
| 7. DM-RS作用？能把端口直接等同物理天线吗？ | 为解调提供信道参考；端口是逻辑信道定义，不能简单等同天线硬件 | T02/T06 |
| 8. TBS与发射编码比特数G相同吗？CRC通过是否代表已满足性能？ | 不同，涉及编码、速率匹配和资源；CRC是正确性证据之一，性能需另验 | T06/T07 |
| 9. 单次测量快20%能宣布优化成功吗？ | 不能；要同配置、预热、重复、排噪声、正确性和系统验证 | T03 |
| 10. AVX处理8个float，n=13如何做？SVE能写死8吗？ | 一向量加5标量或适合指令的安全尾部；SVE用运行时元素数和谓词，不写死 | T04 |
| 11. 一函数快一倍，L1必快一倍吗？ | 不会；该函数占比、关键路径、并行和等待决定上限；还要测系统期限 | T03/T05 |
| 12. core栈显示怪变量就能判断根因吗？AI写的SVE能直接信吗？ | 先匹配二进制/符号/库，考虑优化和缺失内存；AI须独立参考、边界、汇编和系统证据 | T08/T10 |

每题0分=无法解释或核心错误，1分=结论正确但解释/边界不完整，2分=能解释并举反例。把1—5作为C++组、6—8作为NR组、9—11作为测量/SIMD组、12作为定位/AI组；逐题判断，不能只看总分掩盖生命周期或溢出错误。

## 实验D1：标量及数值（C++基础）

在公司Linux用[labs](../labs/README.md)的portable模式构建，读`sat_add16`：输入为两路int16_t，中间int32_t，输出饱和int16_t。手算(30000,30000)、(-30000,-30000)、(-32768,32767)、(1,-1)，再运行测试。故意在纸上把“夹限”改成直接窄化，解释何处与参考不同，不在项目代码做错误修改。

预期：四例为32767、-32768、-1、0。完成：解释提升、范围、窄化和饱和，测试记录含编译器/结果。若失败，首两周额外时间的一半补T01/T04数值。

## 实验D2：资源与时序（NR基础）

运行`python3 labs/nr_example.py`，先手算正常CP、μ=1、12 PRB、10个分配symbol的slot长度、原始RE数量。教学假设每PRB扣12个DM-RS RE、无其他开销、一层、QPSK，再算数据RE和映射bit数量。

预期：0.5ms、原始1440 RE、扣除144后1296 RE、2592 bit。脚本另打印一个限定条件的TBS例子；不能把映射bit数量当TBS。完成：解释假设如何改变答案，把假设和真实配置分开。失败则W2学习优先T02/T06，避免盲查全部规范。

## 实验D3：测量及SIMD（优化基础）

先portable，后在对应CPU上运行avx2/sve。运行自检，再按README指定单个kernel测量；选n=13和65536，至少5次重复，记录中位数/离散度。看小输入是否被调用或计时开销支配，检查是否存在自动向量化。不要对两个架构的裸耗时直接做公平性结论。

预期：所有支持平台上的正确性检查应通过；不保证SIMD一定更快。完成：有原始结果、测量条件和正确性；能解释尾部和为何冷/热缓存不同。失败先补T03，再优化。

## 调整规则

任何生命周期、越界或溢出题0分：实际改代码前完成对应实验解释并经导师检查。NR组低于4/6：W2/W4的5h学习优先资源、DM-RS、TBS和链路，减少扩展模式。测量/SIMD组低于4/6：先保住baseline，W3手写练习缩为一个浮点例子，实际目标仍按导师确认推进。

全组较好也不跳过真实环境/用例基线。已完成任务只在版本、输入、结果和评审能核验后抵扣。两周后用同题解释新反例，再更新计划；诊断改善不等同部门标准通过。
